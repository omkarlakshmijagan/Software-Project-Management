## 📖 About the Repository

This repository brings together **Software Project Management (SPM)** course resources, including lecture presentations, notes in PDF and Word formats, course documentation, a syllabus, and teaching–learning materials (TLMs). It is intended to support organized study, classroom instruction, and revision across **five units**.

**Who can use it?** Undergraduate engineering students, faculty members, and independent learners seeking structured SPM study materials.

> **Note:** This is primarily a teaching and learning resource repository, rather than an executable software application. There is no installation or build process required to read the files.

## 🎯 Learning Goals

Use these materials to develop familiarity with foundational aspects of managing software projects, including planning, estimation, scheduling, monitoring, team coordination, risk, quality, and project delivery. Consult the [official syllabus in this repository](SPM%20Syllabus.pdf) for the exact prescribed unit-level coverage.

## 🚀 Getting Started

1. **Read the [syllabus](SPM%20Syllabus.pdf)** to understand the course requirements.
2. **Study each unit’s PDF notes** from the [unit-wise table](#unit-wise-study-materials).
3. **Review the corresponding PowerPoint presentations** for lecture-by-lecture understanding.
4. **Use the course files and TLMs** as supplementary classroom and teaching references.
5. **Revisit unit notes and presentations** when preparing for assessments.

### Clone the complete repository

```bash
git clone https://github.com/omkarlakshmijagan/Software-Project-Management.git
cd Software-Project-Management
```

Alternatively, on GitHub select **Code → Download ZIP** to download all the materials.

### File viewers

- **PDF:** A web browser or any PDF reader.
- **PPTX:** Microsoft PowerPoint, LibreOffice Impress, or a compatible presentation viewer.
- **DOCX:** Microsoft Word, LibreOffice Writer, or a compatible word processor.
